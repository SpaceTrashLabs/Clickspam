# ClickSpam

A small auto clicker for Windows 10 and 11. It's one portable exe with nothing to install, because it targets .NET Framework 4.8, which ships with Windows. In the app itself it's called Auto Clicker.

## Features

- **Adjustable speed:** set clicks per second (0.01–1000) or per minute (0.01–60000). Switching units keeps the same real speed.
- **Any button:** left, middle or right, with single or double clicks.
- **Two targets:** follow the mouse, or click a fixed point chosen with **Pick on screen**. Picking works across monitors, and Esc cancels.
- **Global hotkeys:** start and stop from any app. The defaults are F6 and F7. Click a key chip to set any key or Ctrl/Alt/Shift combo, or use the same key for both to make it a toggle.
- **Always on top:** the pin button in the title bar keeps the window above others.

## Build

There's no prebuilt download, so you'll need to build it with the [.NET SDK](https://dotnet.microsoft.com/download):

```
git clone https://github.com/SpaceTrashLabs/Clickspam.git
cd Clickspam
dotnet build -c Release
```

The output is `bin\Release\net48\AutoClicker.exe`, a single file you can copy anywhere. Close any running copy before rebuilding, or the copy step fails.

## Good to know

- Clicks won't reach windows running as administrator unless the clicker also runs as administrator (a Windows security restriction called UIPI).
- In fixed-point mode, the cursor jumps to that point before every click, so you can't really use the mouse while it's running. Keep your stop hotkey in mind.
- Settings aren't saved between runs. Speed, target and hotkeys go back to their defaults each time you open the app.
- Some games and apps prohibit auto clickers, so check their rules first.
