# Auto Clicker

Small Windows auto clicker (WPF, .NET Framework 4.8 — runs on any Windows 10/11 with no install).

- Rate in clicks per second (0.01–1000) or clicks per minute (0.01–60000); switching units keeps the same real speed
- Left / middle / right button, single or double click
- Follow the mouse, or click a fixed point chosen with **Pick on screen** (works across monitors; Esc cancels)
- Global start/stop hotkeys: click a key chip and press any key or Ctrl/Alt/Shift combo. Same key for both = toggle. Defaults: F6 start, F7 stop
- Pin button in the title bar keeps the window on top

## Build

```
dotnet build -c Release
```

Output: `bin\Release\net48\AutoClicker.exe` (single file, copy it anywhere). Close any running copy first or the copy step fails.

The icon is generated by `tools\make-icon.ps1` (writes `Assets\app.ico` and `Assets\app-64.png`).

Clicks won't reach windows running as administrator unless the clicker is also run as administrator (Windows UIPI).
